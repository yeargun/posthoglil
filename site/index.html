02 / Runtime

Bytes are only half the story.

Paired browser measurements of the actual shipped artifacts. Lower time is better. No speedup is claimed when the confidence interval includes zero.

What these measurements include

Module import measures parsing, evaluation and module scheduling from a fresh Blob URL; it excludes downloading the source. Init uses memory persistence, autocapture and bootstrapped flags, with recording disabled. Capture measures preparation and queueing of 1,000 events, after 100 warmup calls, and asserts all 1,000 were accepted. Upload, ingestion and replay processing are not timed. These are exploratory microbenchmarks, not end-user latency guarantees.

03 / Integration

Keep your application code.

The preview preserves PostHog’s package layout and canonical declarations. Install it under the posthog-js dependency name so existing imports and React bindings share the same instance.

Loading preview install command…
import posthog from 'posthog-js'
import { PostHogProvider } from 'posthog-js/react'

posthog.init('your-project-token', {
  api_host: 'https://us.i.posthog.com'
})
posthog.capture('checkout', { plan: 'pro' })

Only the root and posthog-js/full/no-external entries contain LilScript internals. Other subpaths remain exact upstream runtimes. The existing @itslil/posthog-js utility package is a separate API.
