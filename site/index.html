Each sample is a fresh browser context on a local, cross-origin-isolated page; PostHog’s build and LilScript’s alternate in ABBA order, 40 samples per module. A time is the median of 15 repetitions after 5 untimed ones; the change is the median of the paired differences with a 95% bootstrap interval, and a verdict needs that interval to exclude zero. Both builds first run the same inputs and must give identical output. A control — PostHog’s build against an identical copy of itself — flagged 3 of 37 rows, so changes of one or two percent are within noise. Import is slower where a module defines most of its functions as top-level arrows, which V8 parses more slowly in module code.

One fresh output build per objective and minifier, run sequentially. LilScript compilation includes optimization and objective scoring with persistent caches disabled and one worker. Original time includes Node startup, esbuild bundling of installed upstream ESM, and the named minifier. It excludes building the upstream package from its original TypeScript sources. Dependency installation, tests and final file compression are excluded on both sides. These are observations on a shared machine, not a build-speed guarantee.
